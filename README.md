# Barberia-TPV
Sharp &amp; Steel TPV Plataforma integral de gestión para barberías. Sharp &amp; Steel TPV optimiza tu tiempo, gestiona citas con agenda dinámica, controla el flujo de caja diario y ofrece analíticas de rendimiento. Una solución profesional, rápida e intuitiva diseñada para transformar tu negocio tradicional en una barbería moderna y eficiente.
